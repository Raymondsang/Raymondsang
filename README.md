## 🔨 What I'm working on

**Freba: plot sales & management system** *(private client project)*
A full-stack platform a land company uses to manage projects, plots, buyers, payments and sale agreements.

- **Back end:** Laravel 13 REST API (PHP 8.4), Sanctum auth, role-based approvals and audit log
- **Front end:** React 19 SPA with Vite and Tailwind CSS 4, plus a buyer self-service portal
- **Features:** payment tracking and emailed receipts, PDF buyer statements and agreements shared via secure tokenised links, plot stage tracking, global search, reports
- **Ops:** queued emails, scheduled daily database and document backups
- **Quality:** PHPUnit feature tests, Playwright end-to-end tests (desktop + mobile), and GitHub Actions CI running tests, Pint, oxlint and builds on every push
